画像認識、音声認識、翻訳、そして大規模言語モデル。ここ 10 年あまりで機械学習が大きく伸びた分野の中心には、**深層学習**（ディープラーニング）がある。層を何段も重ねたニューラルネットを、大量のデータで学習させる手法だ。

ただし、深層学習はどんな問題でも最強というわけではない。第 4 回で見たように、売上や顧客の表のような**表形式データでは、いまも木のアンサンブルが強い**。深層学習の本当の強みは、画素や音の波形のような生のデータから、**役に立つ特徴量を自分で作れること**にある。この記事では、仕組みを押さえたうえで、その線引きを実験で確かめる。

```flow caption="ニューラルネットの学習の 1 周。第 5 回の勾配降下法に、勾配の自動計算が加わる"
C --> D[逆伝播:\n全重みの勾配を自動計算]:::hl
D --> E[最適化手法で\n重みを更新]
E --> F{エポック終了?}

F -- はい --> G([検証データで評価])
```

## ニューラルネットは「足し算と折り曲げ」を積み重ねる

ニューラルネットの 1 層は、2 つの操作でできている。

1. **重み付きの足し算**（線形変換）: 入力の各値に重みを掛けて足す。第 5 回の直線 y = w·x + b を、入力と出力が何個もある形に広げたもの
2. **活性化関数**: 足し算の結果を折り曲げる。代表的な **ReLU** は「負の値を 0 にし、正の値はそのまま通す」だけの関数だ

この層を何段も重ねるのが「深層」の意味だ。活性化関数がないと、足し算を何段重ねても結局 1 回の足し算と同じになり、直線的な関係しか表せない。**折り曲げを挟むことで、曲がった境界や複雑な関係を表せるようになる**。

| 部品 | 役割 | 代表例 |
|---|---|---|
| 線形層（全結合層） | 入力を重み付きで混ぜ合わせる | `nn.Linear` |
| 活性化関数 | 折り曲げて、直線では表せない関係を作る | ReLU、GELU（Transformer でよく使う） |
| 損失関数 | 予測の外れ具合を測る | 分類: 交差エントロピー、回帰: 平均二乗誤差 |
| 正則化 | 過学習を抑える | Dropout（学習中にランダムに一部の出力を 0 にする）、重み減衰 |

### 誤差逆伝播：勾配を後ろから一気に計算する

第 5 回では、損失を w で微分した式を手で書いた。層が何段もあり、重みが何万個もあると、手では書けない。そこで使うのが**誤差逆伝播法**（backpropagation）だ。

出力側から入力側へ向かって、微分の連鎖律（合成関数の微分は、各段の微分の掛け算になる）を順に適用し、すべての重みの勾配を 1 回の後ろ向きの計算で求める。PyTorch などのライブラリは、この計算を**自動で**行う。

```python title="autograd.py" caption="PyTorch に勾配を計算させ、手計算と比べる" {3,7}
import torch  # 深層学習のライブラリ PyTorch

w = torch.tensor(1.5, requires_grad=True)  # ★ 重み。requires_grad=True で「勾配を計算して」と指示する
x, y = torch.tensor(2.0), torch.tensor(5.0)  # 入力 2 と正解 5

loss = (w * x - y) ** 2  # 損失 = (予測 − 正解)²。ここでは (3 − 5)² = 4
loss.backward()  # ★ 誤差逆伝播: 損失から w の勾配を自動で計算する

print(f"自動計算の勾配 {w.grad.item():.1f}")  # PyTorch が求めた勾配
print(f"手計算の勾配   {2 * (1.5 * 2 - 5) * 2:.1f}")  # 2 ×（予測 − 正解）× x
```

```text
自動計算の勾配 -8.0
手計算の勾配   -8.0
```

`loss.backward()` を呼ぶだけで、手計算と同じ勾配が `w.grad` に入る。層が何百段あっても使い方は同じだ。この自動微分があるおかげで、利用者はモデルの形（順伝播）を書くことに集中できる。

## PyTorch で最小のニューラルネットを学習させる

手書き数字データ（8×8 画素、1,797 枚）を 0〜9 に分類する。モデルは、64 画素 → 128 個の中間の値 → 10 クラスの 2 層だ。

```python title="mlp_model.py" caption="データを用意し、2 層のニューラルネットを定義する" {8,12,13}
import numpy as np  # 数値計算のライブラリ
from torch import nn  # ニューラルネットの部品集
from sklearn.datasets import load_digits  # 手書き数字の練習用データ
from sklearn.model_selection import train_test_split  # 学習用とテスト用に分ける

torch.manual_seed(0)  # 乱数を固定して、毎回同じ結果にする
X, y = load_digits(return_X_y=True)  # 画像（64 画素）と、その数字
X = (X / 16.0).astype(np.float32)  # ★ 画素の値 0〜16 を 0〜1 に揃える
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, stratify=y, random_state=0)

mlp = nn.Sequential(  # 層を順につないだモデル
    nn.Linear(64, 128),  # ★ 64 画素を 128 個の値に混ぜ合わせる（重み付きの足し算）
    nn.ReLU(),           # ★ 負の値を 0 にして折り曲げる（活性化関数）
    nn.Dropout(0.2),     # 学習中だけ、2 割の値をランダムに 0 にする（過学習対策）
    nn.Linear(128, 10),  # 10 クラス（0〜9）それぞれの点数にする
)
print(sum(p.numel() for p in mlp.parameters()))  # 重みの総数
```

```text
9610
```

このモデルには 9,610 個の重みがある。これを、第 5 回の勾配降下法で少しずつ直していく。学習の手順は、どんなニューラルネットでもほぼ同じ形になる。

```python title="train.py" caption="ミニバッチで学習する。この形が深層学習の学習ループの基本（mlp_model.py の続き）" {4,13}
def fit(model, epochs=30):  # モデルを学習させる関数
    Xt = torch.tensor(X_tr)  # NumPy の配列を PyTorch のテンソルに変換する
    yt = torch.tensor(y_tr, dtype=torch.long)  # 正解は整数（クラス番号）
    opt = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-2)  # ★ 最適化手法（第 5 回）
    loss_fn = nn.CrossEntropyLoss()  # 分類の損失（交差エントロピー）
    for epoch in range(epochs):  # データ全体を epochs 周する
        model.train()  # 学習モード（Dropout を有効にする）
        perm = torch.randperm(len(Xt))  # 毎周、順番をシャッフルする
        for i in range(0, len(Xt), 32):  # 32 件ずつのミニバッチ
            idx = perm[i:i + 32]  # 今回使うデータの番号
            loss = loss_fn(model(Xt[idx]), yt[idx])  # ① 順伝播して損失を計算
            opt.zero_grad()  # ② 前回の勾配を消す（残っていると足し込まれる）
            loss.backward()  # ★ ③ 誤差逆伝播で全重みの勾配を計算
            opt.step()       # ④ 勾配を使って重みを更新
    return model

def accuracy(model, X_):  # 正解率を計算する関数
    model.eval()  # 評価モード（Dropout を止める）
    with torch.no_grad():  # 予測だけなので勾配は計算しない
        pred = model(torch.tensor(X_)).argmax(1).numpy()  # 最も点数の高いクラスを予測とする
    return (pred == y_te).mean()  # 正解と一致した割合

fit(mlp)  # 学習する
print(f"MLP テスト正解率 {accuracy(mlp, X_te):.3f}")
```

```text
MLP テスト正解率 0.972
```

`fit` の内側の 4 行（順伝播 → 勾配を消す → 逆伝播 → 更新）が、深層学習の学習ループの核心だ。モデルが画像認識用でも言語モデルでも、この 4 行の形は変わらない。

> [!WARNING] model.train() と model.eval() を切り替え忘れない
> Dropout やバッチ正規化は、学習中と評価中で動きが変わる層だ。評価のときに `model.eval()` を呼び忘れると、Dropout が効いたまま予測して正解率が不安定になる。逆に、学習を再開するときに `model.train()` を忘れると、正則化が効かない。

## 1 画素ずらすと分かる、深層学習の本当の強み

このデータでは、ニューラルネット（0.972）は勾配ブースティングとほぼ同じ精度だ。では、深層学習を使う意味はどこにあるのか。テスト画像を**右に 1 画素だけずらして**確かめる。人間にとっては同じ数字だが、モデルにとっては 64 個の入力の値がすべて入れ替わる。

比べるのは 3 つだ。勾配ブースティング、先ほどの MLP、そして画像用のニューラルネット **CNN**（畳み込みニューラルネット）。CNN は、3×3 の小さな窓を画像の上で滑らせて「線」「角」のような局所的な模様を探す。**同じ窓を画像のどこにでも使う**ので、模様の位置が少しずれても同じように反応する。

```python title="cnn_shift.py" caption="テスト画像を 1 画素ずらして、3 つのモデルの正解率を比べる（train.py の続き）" {6,11,13}
from sklearn.ensemble import HistGradientBoostingClassifier  # 勾配ブースティング（第 4 回）

def shift(X_, dx):  # 画像を右に dx 画素ずらす関数
    imgs = X_.reshape(-1, 8, 8)  # 64 個の値を 8×8 の画像の形に戻す
    out = np.zeros_like(imgs)  # 空の画像を用意する
    out[:, :, dx:] = imgs[:, :, :8 - dx]  # ★ 右にずらしてコピーする（左端は空白）
    return out.reshape(-1, 64)  # 64 個の並びに戻す

cnn = nn.Sequential(  # 画像用のニューラルネット
    nn.Unflatten(1, (1, 8, 8)),  # 64 個の値を 1 チャンネル × 8×8 の画像に戻す
    nn.Conv2d(1, 16, 3, padding=1), nn.ReLU(), nn.MaxPool2d(2),  # ★ 3×3 の窓で 16 種類の模様を探す
    nn.Conv2d(16, 32, 3, padding=1), nn.ReLU(),  # 模様の組み合わせ（より大きな形）を探す
    nn.AdaptiveMaxPool2d(1),  # ★ 画像のどこにあったかは捨て、「あったかどうか」だけ残す
    nn.Flatten(), nn.Linear(32, 10))  # 10 クラスの点数にする
fit(cnn)  # MLP と同じ学習ループで学習する

X_sh = shift(X_te, 1)  # 1 画素ずらしたテスト画像
hgb = HistGradientBoostingClassifier(random_state=0).fit(X_tr, y_tr)
print(f"勾配ブースティング 元 {hgb.score(X_te, y_te):.3f}  ずらし {hgb.score(X_sh, y_te):.3f}")
print(f"MLP               元 {accuracy(mlp, X_te):.3f}  ずらし {accuracy(mlp, X_sh):.3f}")
print(f"CNN               元 {accuracy(cnn, X_te):.3f}  ずらし {accuracy(cnn, X_sh):.3f}")
```

```text
勾配ブースティング 元 0.981  ずらし 0.444
MLP               元 0.972  ずらし 0.469
CNN               元 0.976  ずらし 0.787
```

元の画像では 3 つとも 97〜98% で差はない。ところが 1 画素ずらすと、勾配ブースティングと MLP は 44〜47% まで崩れ、CNN は 79% を保った。

勾配ブースティングと MLP は「27 番目の画素が明るければ 7」のように、**特定の位置の画素**に頼って判断している。CNN は「縦線がある」「右上に角がある」という**位置に依存しない模様**を自分で作って判断している。これが「特徴量を自分で作る」ということの具体的な中身だ。

実務では、さらに学習時に画像をランダムにずらしたり回転させたりする**データ拡張**を加え、ずれへの強さを高める。

> [!NOTE] モデルの構造に「データの性質」を埋め込む
> CNN が位置のずれに強いのは、「画像の模様は、どこにあっても同じ意味を持つ」という性質を、同じ窓を使い回す構造として組み込んでいるからだ。深層学習のモデルの設計とは、データの性質を構造に埋め込むことだと言える。

## データの種類でモデルの構造を選ぶ

データの性質ごとに、それを埋め込んだ代表的な構造がある。

| 構造 | 埋め込んでいる性質 | 主なデータ | 使われる場面 |
|---|---|---|---|
| MLP（全結合） | なし（すべての入力を混ぜる） | 表形式、他のモデルの出力 | 大きなモデルの最後の層、埋め込みベクトルの分類 |
| CNN（畳み込み） | 近くのもの同士が関係する。位置がずれても意味は同じ | 画像、音声のスペクトログラム | 外観検査、医用画像、異音検知 |
| RNN / LSTM | 順番に意味がある。直前の状態を引き継ぐ | 時系列、センサー信号 | 小規模な時系列予測、機器の異常検知 |
| Transformer | どの位置同士が関係するかを、データから学ぶ（注意機構） | 文章、画像、音声、時系列 | 翻訳、要約、大規模言語モデル、画像認識 |
| 自己符号化器（オートエンコーダ） | 入力を圧縮して復元する。復元できないものは「普通でない」 | 画像、センサー信号 | 正常データだけで学習する異常検知 |

現在は、Transformer が文章だけでなく画像や音声にも広がり、多くの分野で標準の構造になっている。ただし、データが少ない、計算資源が限られる、推論を小さな機器で動かすといった条件では、CNN や小さなモデルが今も現役だ。

## 活用事例：深層学習が選ばれる現場

| 分野 | 事例 | 深層学習を選ぶ理由 |
|---|---|---|
| 製造 | 製品の外観検査（傷・汚れの検出） | 不良の見た目を人がルールに書き下せない。不良品が少なければ、正常品だけで学習する自己符号化器を使う |
| 製造・インフラ | モーターやポンプの異音検知 | 音の波形から特徴を自分で作れる |
| 医療 | X 線・CT 画像からの病変の検出支援 | 画像の微妙なパターンを学べる |
| 言語 | 問い合わせの自動分類、要約、検索 | 事前学習済みの言語モデルを少量のデータで調整できる |
| 推薦 | 動画・商品の推薦 | 閲覧履歴という順番のある大量のデータを扱える |

製造業での導入は、外観検査・異常検知・予知保全のような効果の見えやすい領域から始まることが多い。国内の導入事例をまとめた記事では、導入がうまくいかない主な原因は技術よりも、データの整備や現場との連携にあると指摘されている。

> [!IMPORTANT] ゼロから学習させない：事前学習済みモデルを使う
> 実務の深層学習で、モデルをゼロから学習させることは少ない。大量のデータで事前に学習済みのモデルを取ってきて、手元の少量のデータで最後の部分だけを調整する（ファインチューニング、転移学習）。数百枚の画像や数千件の文章でも実用的な精度が出るのは、このためだ。

## 表形式データの境界線：いつ深層学習をやめるか

表形式データで深層学習が勝ちにくい理由は、第 4 回で Grinsztajn らの研究として整理した（滑らかな関数を学びがち、無関係な列に弱い、列の向きを保たない）。今回の実験に当てはめると、表の各列は「位置 = 意味」なので、CNN の「位置がずれても同じ」という性質は役に立たない。

一方で、表形式データにも深層学習が入り込みつつある。2025 年に Nature に掲載された **TabPFN** は、数百万の合成データセットで事前に学習した Transformer で、**1 万件以下**のデータでは、4 時間調整した強い手法のアンサンブルを 2.8 秒で上回ったと報告されている。ただし対象は小〜中規模のデータに限られる。

```flow caption="深層学習を使うかどうかの判断"
A([データの種類]) --> B{画像・音声・文章?}
B -- はい --> C{事前学習済み\nモデルがある?}
C -- はい --> D([ファインチューニング]):::hl
C -- いいえ --> E([CNN / Transformer を学習])
B -- いいえ --> F{表形式で\n1 万件以下?}
F -- はい --> G([勾配ブースティングと\n表の基盤モデルを比べる])
F -- いいえ --> H([勾配ブースティング\n第 4 回])
```

| 観点 | 深層学習を選ぶ | 木のアンサンブルにとどめる |
|---|---|---|
| データの種類 | 画像・音声・文章・長い系列 | 列ごとに意味の違う表形式 |
| 特徴量 | 人が作るのが難しい（画素、波形） | 業務知識で作れる（件数、比率、期間） |
| データ量 | 多い、または事前学習済みモデルが使える | 数百〜数百万件 |
| 計算資源 | GPU を用意できる | CPU で十分にしたい |
| 説明 | 根拠の説明はあまり求められない | 理由の説明が求められる |
| 組み合わせ | 文章や画像から埋め込みベクトルを作り、表の列として木のモデルに渡す | 同左（両方の強みを使う） |

## 深層学習のチェックリスト

| 確かめること | 対応する節 |
|---|---|
| 同じデータで勾配ブースティングの点数を先に測り、基準にした | 1 画素ずらすと分かる |
| 入力の尺度を揃えた（画素を 0〜1 にするなど） | 最小のニューラルネット |
| 学習ループで勾配を毎回消している（`zero_grad`） | 学習ループ |
| 学習と評価で `train()` / `eval()` を切り替えた | 学習ループ |
| データの性質に合った構造（CNN・Transformer など）を選んだ | 構造を選ぶ |
| ゼロから学習させる前に、事前学習済みモデルを探した | 活用事例 |

深層学習は、特徴量を人が作れない生データで真価を発揮する。表形式データでは、まず木のアンサンブルを基準にし、深層学習はそれを超えるときにだけ使えばよい。

ここまでの 6 回は、正解のあるデータから学ぶ**教師あり学習**だった。次回「[正解のない分類をどう評価するか](2026-09-30-ml-basics-7-clustering.html)」からは、正解のないデータから構造を見つける**教師なし学習**に進む。
